# ADR-016: Geopolitical Oracle — Predictions anchored on conflict data

**Date**: 2026-03-09
**Status**: Proposed
**Author**: Sim (architect) + Opus (gatekeeper)
**Dependencies**: ADR-012 (deterministic path), ADR-010 (consensus_meta), ADR-014 (domain pattern)

---

## 1. Context

Professor Jiang Xueqin (Yale, "Predictive History") formulated three geopolitical predictions in May 2024 based on historical cycles and game theory. Two of three came true. His methodology is exactly the type of claim EPP is designed to evaluate: structured opinions + verifiable data.

Combining the two EPP paths is the value proposition:
- Epistemic path: the LLMs deliberate (VERIFY)
- Deterministic path: ACLED data anchors the facts (ADR-012)

Result: an attestation that says "this prediction is CONTESTED at 0.55 with entropy 0.8, anchored on 847 verifiable conflict events".

---

## 2. Decision

### 2.1 — ACLEDAdapter

File: `services/sources/adapters/acled.py`

ACLED API:
- Auth: OAuth2 — POST `acleddata.com/oauth/token` → bearer token (24h)
- Credentials: `ACLED_EMAIL` + `ACLED_PASSWORD` (env vars only)
- Events endpoint: `GET /api/acled/read` — conflict events
- CAST endpoint: `GET /api/cast/read` — 6-period forecasts
- Format: JSON, pagination `&page=N`, limit 5000/page
- Filters: country, event_date, event_type, fatalities, actor1, etc.

Two modes via the `mode` field of the query dict:
- `events`: fetch real events (country/date/type)
- `forecast`: fetch CAST predictions

Score normalization: `min(1.0, current_events / baseline_12months)`
- `> 2x baseline` → status "escalation"
- `< 0.5x baseline` → status "de-escalation"
- Otherwise → status "stable"

### 2.2 — MetrologicalFrame `geopolitical_forecast_v1.0`

Domain `geopolitical_analysis`, metric `conflict_forecast_assessment`.
Authoritative sources: `acled_events`, `acled_cast`.
`esmm_bypass: false` — the two paths coexist.

### 2.3 — Jiang claims

8 structured claims:
- 3 Jiang predictions (Iran terrain, proxies, Hormuz)
- 2 resolved predictions (Trump, US-Iran ops) — calibration
- 1 CAST vs Jiang comparison (forecast delta)
- 2 controls (Yemen = active conflict, Switzerland = no conflict)

Each claim has an optional `acled_query` for the deterministic path.

### 2.4 — Script `scenario_jiang.py`

Two passes per claim:
1. Epistemic VERIFY (`run_pipeline`, like `scenario_6_1`)
2. Deterministic ACLED (`run_pipeline` with `claim_nature=DETERMINISTIC`)
3. Concordance/discordance comparison

Temporary DBs per claim. Timestamped JSON output.

## 5. Constraints

- ACLED credentials in env vars only
- Rate limit: max 10 requests per claim, pagination 5000 lines
- Temporary DBs (no pollution of `epp_devnet.db`)
- Network required for ACLED; if unreachable, VERIFY runs alone

4. Integration of the deterministic path (pass 2)
5. Concordance + display
