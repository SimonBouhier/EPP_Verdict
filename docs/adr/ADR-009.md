# ADR-009 : Language Neutrality in ESMM Protocol
**Date** : 2026-02-15
**Statut** : Actif

## Contexte
Les prompts ESMM etaient en francais, causant un mimetisme linguistique
des modeles. Le consensus par hash exact ecrasait les nuances cross-langue.

## Decision
- Les langues sont des consommables, comme les modeles.
- Format de sortie structure : triplet JSON avec relations canoniques anglaises.
- Normalisation semantique langue-agnostique (embedding-based, Pass 2).
- Langue de restitution = celle de l'utilisateur.
- Triplets CONTESTED (ambiguity_detected=True) suivent le flux normal.
  Le flag est informatif, pas bloquant. COMMUNITY_DECISION_REQUIRED.

## Consequences
- Les prompts sont en anglais avec directive "MUST be in English".
- Le seuil semantic merge (0.85) est un point de depart, ajustable.
- Le traitement des triplets contestes est une decision communautaire.
