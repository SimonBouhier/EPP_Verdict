**Date**: 2026-02-08

## Context
The legacy tiers (low/medium/high) did not capture the epistemic semantics. The "verified" tier requires an external source (`source_anchor`).

## Decision
4 ordered tiers: `sandbox < proposition < validated < verified` (`attestation.py:205`).
Legacy mapping: low→sandbox, medium→proposition, high→validated (`attestation.py:209-212`).

## Consequences
Existing attestations rely on these tiers. Any name or semantic change breaks compatibility. The Phase 0.3 tests depend on them.
