**Date**: 2026-02-05
**Status**: Active

## Context
An attestation is a timestamped epistemic fact. Modifying it after the fact would invalidate its signature and hash.

## Decision
Only the Solana submission fields (`solana_tx_signature`, `submission_status`) may be updated (`engine.py:3085,3119`). The epistemic content is immutable. Existing annotation: `AUDIT[A4-004]` at `engine.py:3098`.

## Consequences
To correct an attestation, create a new one with `previous_hash` pointing to the old one. NEVER `UPDATE` the content.
