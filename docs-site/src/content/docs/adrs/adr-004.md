**Date**: 2026-02-05
**Status**: Active

## Context
`INSERT OR REPLACE` destroys existing metadata (created_at, embeddings, degree) on replacement. A re-injected concept must keep its history.

## Decision
`INSERT OR IGNORE` on the `concepts` table (`engine.py:411,1226`).
If the concept already exists, nothing is touched.

## Consequences
To update an existing concept, use an explicit `UPDATE`, not `INSERT OR REPLACE`.
