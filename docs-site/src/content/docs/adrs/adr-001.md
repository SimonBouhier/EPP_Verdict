**Date**: 2026-02-06
**Status**: Active

## Context
Solana has no native float type. Consensus scores and 5D signature components are floats in [0.0, 1.0] on the Python side.

## Decision
Multiply by `SCORE_SCALE=10000` and store as `u16` (`bridge.py:28`).
Precision: 4 decimals. Roundtrip tested: `decode(encode(f)) ≈ f` with tolerance 1e-4.

## Consequences
Do NOT change `SCORE_SCALE` without migrating all existing on-chain attestations.
