**Date**: 2026-02-10
**Status**: Active

## Context
Two simultaneous runs on the same question would produce two distinct attestations (timestamps, slightly different consensus).

## Decision
A single active ESMM run per question. The orchestrator owns the run (D1).
Verified in `pipeline.py:80,105` — the pipeline does NOT create an ESMM run.

## Consequences
Do NOT parallelize ESMM runs without revisiting attestation deduplication.
