**Date**: 2026-02-15
**Status**: Active

## Context
The ESMM prompts were in French, causing linguistic mimicry from the models. Hash-exact consensus erased cross-language nuances.

## Decision
- Languages are consumables, like models.
- Structured output format: JSON triplet with English canonical relations.
- Language-agnostic semantic normalization (embedding-based, Pass 2).
- Output language = the user's language.
- CONTESTED triplets (`ambiguity_detected=True`) follow the normal flow. The flag is informative, not blocking. `COMMUNITY_DECISION_REQUIRED`.

## Consequences
- Prompts are in English with the directive "MUST be in English".
- The semantic merge threshold (0.85) is a starting point, adjustable.
- The treatment of contested triplets is a community decision.
