**Date**: 2026-02-05
**Status**: Active

## Context
The claim hash uniquely identifies a triplet within a metrological frame. It serves as the deduplication key and the chaining key for attestations.

## Decision
SHA-256 of the canonical JSON `{subject, predicate, object, metrological_frame}` (`attestation.py:173,200`). UTF-8 encoding, sorted keys, compact separators.

## Consequences
Changing the hash formula breaks chaining (`previous_hash`) and deduplication. On-chain attestations reference this hash. Immutable.
